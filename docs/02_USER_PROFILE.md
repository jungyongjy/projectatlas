# Overview

Atlas is intentionally designed around a **single primary user** rather than a generic fitness audience.

This document defines that user.

Every recommendation throughout the handbook should be evaluated against this profile before implementation.

Whenever there is conflict between scientific optimisation and practical sustainability, this document takes priority.

# Long-Term Identity

Atlas is not designed around achieving one race time.

It is designed around building the following identity.

> **A well-rounded hybrid athlete who is strong, muscular, aerobically fit, athletic, mobile, injury-resistant, and capable of maintaining that lifestyle for decades.**

This identity should remain stable even as individual goals evolve.

---

# Long-Term Vision

The ideal future version of the user would:

- Weigh approximately **84 kg**
- Maintain roughly **12% body fat**
- Run 2.4 km in **10:30**
- Maintain a consistent Zone 2 pace of **6:30/km**
- Continue making gradual strength progress
- Be noticeably athletic and mobile
- Have excellent posture
- Inspire others through consistency rather than intensity

The emphasis is on sustainability rather than peak performance.

---

# Training Philosophy

The user does **not** want to become:

- A powerlifter
- A bodybuilder
- A marathon specialist
- A CrossFit athlete

Instead, training should balance:

- Strength
- Hypertrophy
- Cardiovascular fitness
- Mobility
- Athleticism
- Injury resilience

No single quality should dominate at the expense of the others.

# Current Programming Philosophy

✓ Pallof Press replaces Russian Twists

✓ Standing Calf Raises remain

✓ Micro-plyometrics added

✓ Machine compounds retained

✓ Direct arm work retained

Atlas should treat these as established design decisions.

# Design Preferences

The user values:

- Evidence-informed decisions
- High ROI exercises
- Functional athleticism
- Simplicity
- Sustainability

The user dislikes:

- Unnecessary complexity
- Exercise variety for its own sake
- Constant programme redesign
- Excessive fatigue

Atlas should evolve through refinement rather than replacement.

---

# Primary Constraints

Every recommendation throughout Atlas should satisfy these constraints.

✓ Fits within existing weekly schedule.

✓ Supports running goals.

✓ Preserves muscular physique.

✓ Requires minimal additional equipment.

✓ Is sustainable long-term.

✓ Respects user preferences.

---

# Definition of Success

Atlas has successfully fulfilled this user profile when it enables the user to:

- Achieve a 10:30 2.4 km.
- Improve Zone 2 pace to approximately 6:30/km.
- Maintain or slightly improve physique.
- Continue gradual strength progression.
- Remain healthy and injury-resistant.
- Follow the programme consistently for years without major redesign.
