The long run is the weekly aerobic cornerstone. Performed at an easy, conversational pace, it builds the physiological and psychological infrastructure that supports all faster running.

## Purpose

The long run develops:

- Aerobic capacity (total work the cardiovascular system can sustain)
- Fat oxidation (ability to use fat as fuel, sparing glycogen)
- Muscular endurance (durability of muscles, tendons, and joints)
- Capillary and mitochondrial density
- Mental resilience (comfort with sustained effort)
- Running economy at easy paces

## Execution

| Parameter | Guideline |
|-----------|-----------|
| **Distance** | 7–10 km |
| **Duration** | 45–60 minutes |
| **Pace** | Zone 2: conversational |
| **RPE** | 3–4 out of 10 |
| **Heart Rate** | ~140–150 bpm |
| **Frequency** | Once per week (Sunday) |

### Session Structure

1. **Warm-up**: First 5–10 minutes at very easy pace
2. **Main Block**: 7–10 km at conversational Zone 2 pace
3. **Cool-down**: Final 5 minutes at very easy pace

<InfoBox title="The long run is not a race">
There is no target pace for the long run beyond staying in Zone 2. The adaptation comes from time on feet, not from speed. Finishing a 10 km long run at 7:00/km is more productive than finishing 7 km at 6:00/km.
</InfoBox>

## Benefits

| Benefit | Mechanism |
|---------|-----------|
| **↑ Aerobic capacity** | Sustained cardiac output over extended duration |
| **↑ Fat oxidation** | Enhanced mitochondrial fatty acid transport |
| **↑ Capillary density** | Chronic low-intensity stimulus promotes angiogenesis |
| **↑ Muscular durability** | Tendons, ligaments, and muscles adapt to sustained loading |
| **↑ Mental resilience** | Comfort with being on your feet for extended periods |
| **↑ Weekly mileage** | Safe way to increase total running volume |

## Progression

The long run should progress conservatively. Aggressive distance increases are the most common cause of running overuse injuries.

| Stage | Distance | When to Progress |
|-------|----------|-----------------|
| **Beginner** | 7 km | 4+ weeks consistent |
| **Intermediate** | 8 km | 4+ weeks consistent |
| **Current** | 7–10 km | – |
| **Advanced** | 10 km | Maintain at this distance |

<WarningBox title="The 10% rule is not a target">
Traditional advice suggests increasing weekly mileage by no more than 10% per week. This is a ceiling, not a floor. For a hybrid athlete managing concurrent training, even slower progression (5% or less) may be appropriate.
</WarningBox>

## Common Mistakes

### Running Too Fast

The most common long run error. Running at "moderate" pace rather than truly easy pace increases fatigue without providing additional aerobic benefit. The specific adaptations of Zone 2 training require Zone 2 intensity.

### Progressive Acceleration

Starting easy and gradually accelerating as the run progresses, often unconsciously. This turns an easy aerobic run into an unplanned moderate-to-hard effort. Use heart rate or the talk test to maintain consistent effort.

### Skipping the Long Run

When time is limited, the long run is often the first session sacrificed. This is a mistake, the long run provides adaptations (capillary density, fat oxidation, durability) that no other session replicates.

### Running on Tired Legs

Sunday follows Saturday gym. If Saturday's session was leg-dominant, legs may feel heavy for the long run. This is acceptable, the long run is easy enough that moderate fatigue should not prevent completion.

<CoachNote>
The long run is a discipline session as much as a physiological one. The ability to run for an hour without entertainment, without pace pressure, and without external validation is a skill. Develop it. It transfers to every other aspect of training.
</CoachNote>

<ScientificNote>
Low-intensity sustained exercise stimulates mitochondrial biogenesis through AMPK and PGC-1α signalling pathways. These adaptations occur primarily in Type I (slow-twitch) muscle fibres and accumulate gradually over months and years. There is no shortcut, the long run cannot be replaced by higher-intensity work.
</ScientificNote>
