The running system is built around three sessions per week, each with a distinct purpose.

<img src="/images/running/running-gait.svg" alt="Running gait cycle showing the stance and swing phases" className="my-6 w-full max-w-md rounded-lg border border-atlas-border" />

## The Three Sessions

| Session | Day | Purpose |
|---------|-----|---------|
| Hard Run | Tuesday | Intervals, threshold, or strides |
| Easy Zone 2 | Thursday | Aerobic base development |
| Long Run | Saturday | Endurance and mental resilience |

<InfoBox title="Why three sessions?">
Three running sessions per week is the minimum effective dose for consistent aerobic improvement while allowing three strength sessions. Four or more running days would interfere with gym recovery.
</InfoBox>

## Running Priority

Running takes priority in the Atlas system. The primary measurable performance goal is improving the 2.4 km run.

Strength training exists to **support** running rather than compete with it.

## Hard Run Rotation

Tuesday hard runs rotate between four workout types:

1. **400 m Intervals**: Speed and VO₂max development
2. **Norwegian 4×4**: Maximal aerobic stimulus
3. **Threshold Run**: Sustained lactate threshold effort
4. **Strides**: Neuromuscular coordination and economy

This rotation ensures every major running quality is developed without excessive specialisation.

<CoachNote>
Never increase multiple variables simultaneously. Improve consistency first, then technique, then running economy, then pace, and finally mileage, in that order.
</CoachNote>
