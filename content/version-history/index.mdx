Atlas follows [Semantic Versioning](https://semver.org/): `MAJOR.MINOR.PATCH`.

- **MAJOR** — Significant changes to training philosophy, programme structure, or the application itself
- **MINOR** — New handbook content, new features, or revised recommendations
- **PATCH** — Corrections, clarifications, or small refinements

---

## Version 1.0.0

**Released:** 2026-08-01

Initial release of Project Atlas — the complete hybrid athlete handbook.

### Added

- Complete Blueprint section with philosophy, goals, principles, and weekly schedule
- Running handbook with 10 pages covering all training modalities
- Strength handbook with 8 pages documenting the complete programming system
- Mobility handbook with 7 pages organised by body region
- Nutrition handbook with 9 pages of practical, evidence-informed guidance
- Exercise Library with 21 individual exercise reference pages
- Decision Engine with 7 interactive decision trees
- Scientific Appendix with 8 evidence summaries
- Interactive Weekly Checklist with localStorage persistence
- Full-text search with Ctrl+K command palette
- Documentation shell with sidebar, breadcrumbs, and responsive layout
- Dark theme UI modelled on professional software documentation

### Notes

Version 1.0 represents the complete initial release. Every section specified in the product architecture has been implemented. The application is deployed on Vercel and ready for long-term use.

The training system documented in this release reflects approximately 7 years of training experience, refined through evidence review and practical testing. Future versions will refine recommendations based on new evidence and experience — not redesign the system from scratch.

<InfoBox title="Atlas evolves slowly by design">
Major redesigns should be rare. The programme documented here is intended to remain stable, evolving through refinement rather than replacement. If a recommendation changes, it should change because the evidence or the athlete has changed — not because a new training trend has appeared.
</InfoBox>
